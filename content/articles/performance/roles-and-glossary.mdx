## Who sees what

Access in Performance comes from two things: a person's **role**, and where they sit in the **reporting line**.

| | Sees | Can |
| --- | --- | --- |
| Super admin, Admin, HR manager | Everyone's performance records | Change every setting, run cycles, start any review on the reviewer's behalf, calibrate everyone, use reports |
| Anyone with people under them | Their own records, and those of everyone below them in the reporting line | Write their reports' reviews, assign and approve tasks, set team objectives, hold one-to-ones, calibrate their line if they manage managers |
| Everyone | Their own records | Write a self review, add and update their own tasks, give feedback, take part in one-to-ones |

The **Line manager** role adds the admin dashboard for managers; without it, they do the same work from the employee portal and the app.

Four things work differently:

- **One-to-ones** can only be changed by the two people in them. HR, and managers above the lead, can read them, but nobody sees someone else's private notes.
- **360° feedback** is seen by the people the sender chose under **Who can see it**.
- **An appraisal's conclusion** is hidden from the employee until the review is complete.
- **Appraisals whose template has Restrict Visibility on** can only be viewed by HR and the person's direct manager.

## Glossary

| Term | Meaning |
| --- | --- |
| Appraisal, review | One person's review in a cycle. Manager reviews hold the final score; employees can also write a self review. CentaHR uses both words. |
| Calibration | Comparing finished manager reviews across teams, and adjusting scores with a reason. |
| Check-in | A task owner updating their progress. Reminders follow the task policies. |
| Competency | A quality you appraise people on, such as Communication. Each holds questions. |
| Conclusion | The end of a review: final summary, strengths, areas for improvement, final score and recommendation. |
| Cycle | A dated period, such as H1 2026, that holds appraisals, tasks and objectives. |
| Default manager | The person who stands in for anyone without a line manager. Set under your avatar menu → Users → Approvals. |
| Final score | A score out of 100 on a manager review, set by the reviewer and changed only by calibration. |
| Line manager | The person someone reports to. They write the person's appraisal and approve their tasks. |
| Objective | A company or team aim for a cycle. Task progress rolls up to it. |
| Recommendation | Promote, Hold or Exit, chosen in the conclusion. |
| Shared task | One task for a whole team, with one progress bar. Rated for the team result and each person's contribution. |
| Suggested score | The weighted average of a person's task ratings, where each star is worth 20 points. |
| Task | What someone should deliver in a cycle; other systems call it a goal. |
| Team result share | The part of a shared task's score that comes from the team's result. Set in general settings. |
| Template | Decides which sections a review has (questions, tasks, feedback, attendance) and which questions it asks. |
| Values | The heading for a review's questions, grouped by competency. |
| Weight | How much a task counts towards the suggested score, from 0 to 100. |
