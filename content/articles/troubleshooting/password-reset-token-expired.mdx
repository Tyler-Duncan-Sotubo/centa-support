## What the page says

| Title | Why it happens |
| --- | --- |
| This link has expired | Password reset links work for 24 hours. |
| This link has already been used | Each link works once. Opening it again, refreshing the page, or opening it on a second device uses it up. |
| This link isn't valid | The link is incomplete, or a newer link has replaced it. Asking for a new reset link cancels the ones before. |

## Get a new link

**Resetting your password:**

1. Click **Request a new reset link**. It opens **Forgot your password?**.
2. Enter your work email and click **Send reset link**.
3. Open the **newest** email and use its link straight away, in one browser.

**Joining your team:** ask your HR admin to send you a new invitation. Then use the link in the newest invitation email.

## Avoid it next time

- Use the link as soon as it arrives.
- Ask for one reset email, and use the newest if you have several.
- Open the link once, on one device, and finish in one go.

If the new link doesn't arrive, see [you didn't get an email](/troubleshooting/emails-not-arriving).
