If your company uses two-step sign-in, CentaHR emails you a 6-digit code after your password when you haven't signed in for three days, and the first time you sign in. You type it on **Confirm it's you**.

## Messages you may see

| Message | What it means | What to do |
| --- | --- | --- |
| Invalid verification code | The code doesn't match the newest one sent. | Check the digits and try again. If you asked for more than one code, use the newest email. |
| Verification code expired | Codes work for 10 minutes. | Click **Send a new code**, and use it straight away. |

## The code didn't arrive

1. Wait a minute: emails can take a little while.
2. Check your spam or junk folder for an email from noreply@centahr.com.
3. Click **Send a new code** under **Didn't get it?**. You'll see “A new code is on its way.”
4. Still nothing? See [you didn't get an email](/troubleshooting/emails-not-arriving).

## For HR admins

Two-step sign-in is set for the whole company under your avatar menu → **Users** → **Two-step sign-in**. It's on to start with. Keep it on: it stops someone with a stolen password from getting in.
